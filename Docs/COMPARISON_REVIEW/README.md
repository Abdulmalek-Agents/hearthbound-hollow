**Hearthbound Hollow** is by far the most production-mature of the three — a narrative-complete vertical slice with a
fully built 7-pillar cozy loop, ~25k LOC, hand-written writing, and a prior critic sign-off (board average **8.6/10**).

Top action items: run **G-Engage** for Hearthbound, and **resolve the "Hearth-" name collision** before either cozy title reaches a storefront.
