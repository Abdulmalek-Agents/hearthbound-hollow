How to read these maps

Each scene is drawn top‑down (plan view) at an approximate metric scale — a faint 1‑metre grid sits under every map, with a scale bar and a 🧭 plan‑view marker. Every asset is a chip: a representative emoji icon, its asset code below it (e.g. ENV-HOL-003), and its full name on hover. The colour ring shows the discipline; a small badge shows whether the asset is best authored/seen top‑down, from the side, or both.

TOP read in plan (footprint & placement) SIDE read in elevation (height, silhouette) → see Side Views BOTH needs plan + elevation
Multiples (walls, fences, road tiles, trees) are drawn once as a labelled set on the structure itself (e.g. the lane walls are ENV-LANE-004 ×14). The per‑scene table under each map lists every placed asset with its approximate position. The authoritative per‑asset data lives in manifests/asset_manifest.csv.
