# 🎨 Hearthbound Hollow — Art Production Studio Roster
### The named studio that builds the Mission 1–2 vertical slice
> Branch: `feat/mission-1-2-architecture` · Engine: Unity 6000.4.4f1 (URP‑Mobile) · Scope: Mission 1 "Opening the Hollow" + Mission 2 "The Widower's Request"

This roster convenes a **45‑person virtual studio** across Direction, Production, the full Art org (Concept, Environment, Character, Texture, Lighting, VFX, Tech Art, UI/UX, Animation, Cinematics), Audio, Design, Narrative, Engineering, and QA. Names in **bold** already appear as canon owners in the Mission 1‑2 Focus folder and the Master Bible; the art‑specific roles extend that studio so every asset has an owner.

> **Discipline carried into every seat:** the *Cozy Contract* holds always (nothing punishes kindness; no "FAILED" string ever ships; Auto‑Complete on every mini‑game), there is **no dark monetization**, and **all dialogue is hand‑written** — AI‑generated dialogue is forbidden (GAME_DESIGN §9 Pillar 1).

## 9. Convening Protocol (how a task picks its team)

Following the studio handbook (`CLAUDE.md §2`), every art task **convenes the minimum roster it needs** and routes through the right discipline skill:

| Task type | Lead owner | Convenes |
|---|---|---|
| New scene set‑dress | Brynja Søl | Yara Senn (color script) → Greta Halloran (import) → Lukas/Nessa (dress) → Émile Roux (light) → Petra Knoll (audit) |
| New villager | Tobias Renn | Mira Salonen (concept) → Dahlia Voss (reskin) → Otto Lindgren (anim) → Sigrid Holm (eyes) → Iva Brandt (motif) |
| Memory‑orb work | Devin Marlowe | Nadia Frost (VFX) → Jonas Pelt (mini‑game FX) → Kestrel Aho (wire) → Linnet Pao (feel) |
| Any UI surface | Pia Lindqvist | Esme Cordray (UX) + Pell Doyne (comfort) → Wren Aldous (build) |
| Any change at all | — | **`cozy-review`**: Marielle Voss + Pell Doyne sign the Cozy Contract before merge |

> Every deliverable lands with a `Docs/PROGRESS.md` note (files touched, follow‑ups, deviations) — **no art lands without it** (`CLAUDE.md §3.6`).
